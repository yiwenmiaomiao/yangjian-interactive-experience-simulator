# 杨戬故事模拟器

**你在和杨戬说话。**

---

## 这是什么？

一个可以聊天的人工智能故事游戏。你会与传说中的战神杨戬相遇——他会和你说话、会观察你的反应、会影响故事的走向。

故事是**实时生成**的，不局限于某个固定场景。你的每一个选择，都会让故事走向不同的方向。

---

## 能做什么？

**1. 和杨戬对话**
他有自己的性格和记忆。他不会机械回答，而是会根据自己是谁、目前处境如何来决定怎么说、怎么做。

**2. 探索故事**
故事有主线剧情，也有支线。你的选择会解锁不同的情节分支，影响杨戬对你的态度。

**3. 遇到各种角色**
故事中的角色会随着剧情展开而出现——他们有自己的故事、性格和行事逻辑。

**4. 不同的结局**
同一个开局，取决于你如何与杨戬互动、如何选择，结局可能截然不同。

---

## 怎么玩？

通过 iMessage（手机短信）和杨戬对话，就像和朋友发消息一样自然。

**一些小提示：**
- 杨戬不会主动伤人，但对挑衅他的行为也不会客气
- 他有记忆，会记得你们之前说过什么
- 有些选项需要你主动选择，有些是自然对话中触发的
- 如果故事停下来，可以换个方式和他说话

---

## 技术细节（如果你好奇）

- 由大语言模型驱动，故事实时生成，不是录制好的剧本
- 杨戬是一个独立的"角色大脑"，有自己的人物设定和行事逻辑
- 有一个"导演"系统负责协调故事节奏和角色行动
- 故事有预先设计的主线框架，但具体情节由你的选择和大模型的实时判断共同决定

---

## 关于杨戬

杨戬是中国神话中的著名战神——三尖两刃刀、啸天犬、劈山救母。在这个故事里，你遇到的杨戬是一个经历过很多事的成熟男人，有自己的骄傲、秘密和情感。

他不是对所有人都热情，也不是对所有人都冷淡。他的反应取决于你是谁、你怎么说、你怎么做。
